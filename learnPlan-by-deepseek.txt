## Plan: Python for Linux System Administration

This plan assumes you know the basics of Python programming, such as variables, data types, loops (`for`, `while`), conditionals (`if`, `else`), functions, basic syntax (indentation!), and perhaps writing a simple script. If these aren't solid, refer to resources like [Python.org](https://docs.python.org/3/tutorial/) or the suggestions in the initial phase.

### Phase 1: Reinforce Fundamentals & Crucial System Interaction

This phase builds *directly* upon your existing Python knowledge but focuses intensely on tools relevant to Linux sysadmin work. Don't be afraid to revisit basics here if needed, through practical application.

| **Topic** | **Learning Resources (Examples)** |
|---|---|
| **1. Master `subprocess` Module:** Learn how to run shell commands from Python safely and effectively. This is the primary bridge between Python scripts and Linux system operations.
    *   `subprocess.run()`
    *   Capturing output (`stdout`, `stderr`)
    *   Checking return codes
    *   Running multiple commands sequentially
    *   Examples: Run a single command (e.g., `ls -l`), capture its output, check if it succeeded. Then chain two commands (e.g., `find /home/user -name '*.log' > log_files.txt`) |
| **2. Focus on File I/O & Text Processing:** Apply Python's file handling skills to Linux-centric tasks.
    *   Reading/Writing files (`open()`, context managers `with`)
    *   Working with common data structures: Lists (often for command output/lines), Strings, Dictionaries
    *   Using basic String methods (`strip()`, `split()`, `join()`) – this is crucial!
    *   Examples: Read `/etc/passwd` into a list of dictionaries. Write the contents of one file to another. Split a large log file by lines containing specific keywords |
| **3. Deep Dive into Regular Expressions (Regex):** Learn how Python's `re` module can power complex text pattern matching and manipulation, often used for parsing logs or config files.
    *   Basic regex syntax (`.` , `^`, `$`, `*`, `+`, `?`, `[...]`, `\d`, `\D`)
    *   Using `re.search()`, `re.match()`
    *   Using `re.findall()` to extract multiple instances
    *   Using `re.sub()` for replacement
    *   Examples: Check if a log line matches an expected format. Extract IP addresses from logs using regex patterns. Validate file names against specific patterns |
| **4. Error Handling (`try`, `except`):** Make your scripts robust.
    *   Understanding common exceptions (FileNotFoundError, PermissionError, CalledProcessError – important for subprocess)
    *   Catching relevant errors
    *   Logging errors appropriately (see Phase 2/3 on logging)
    *   Examples: Try to read a specific file and handle the case it doesn't exist. Run a command via `subprocess.run()` and check its return code, handling failure if necessary |
| **5. Command-Line Arguments (`sys.argv`):** Learn how to make your Python scripts interact with the user or be called from other commands.
    *   Accessing arguments using `sys.argv`
    *   Simple argument validation (e.g., checking a required flag exists)
    *   Examples: Create a script that accepts a filename as an argument (`python my_script.py file.txt`) and processes it. A script that runs only if called with the `-v` verbose flag |

### Phase 2: Structured Scripting & Automation Techniques

Now you move from individual tool mastery to combining them effectively for specific system admin goals.

| **Topic** | **Learning Resources (Examples)** |
|---|---|
| **1. Configuration Files (YAML/JSON):** Learn common data serialization formats used in configuration.
    *   Using the `yaml` library (`PyYAML`) – understand anchors and aliases if possible
    *   Using the `json` module standard library
    *   Reading config files, modifying simple structures, writing back
    *   Examples: Read an Ansible playbook variable file (`.yml/.yaml`). Parse a JSON configuration of services. Write a script that reads user settings from a `.ini` or `.cfg` file |
| **2. Command-Line Argument Parsing (`argparse`):** Properly handle command-line inputs for your scripts.
    *   Defining arguments (`nargs`, `type`, `choices`)
    *   Positional vs. optional arguments
    *   Help messages automatically generated
    *   Examples: Create a script to monitor disk usage that accepts parameters like `-d /tmp` (device) or `--threshold 90`. A configuration management script that takes hostnames, credentials type, and config file path |
| **3. Logging:** Implement robust logging instead of basic print statements.
    *   Configuring log levels (`DEBUG`, `INFO`, `WARNING`, `ERROR`)
    *   Specifying log format (including timestamps, logger names)
    *   Logging to console vs. files
    *   Rotating logs using `logging.handlers` like `RotatingFileHandler`
    *   Examples: Set up a script with different logging levels for verbose (`DEBUG`), normal operation (`INFO`), warnings (`WARNING`), and errors (`ERROR`). Configure log rotation *within* your Python script itself (conceptually, understand how it relates to system `logrotate`) |
| **4. Working with Large Text Files/Log Data:** Handle large datasets efficiently.
    *   Using the `shutil.which()` function – find commands easily
    *   Using generators for line-by-line processing of huge files or command output (optional but powerful)
    *   Introduction to asynchronous programming (`asyncio`) basics and its use with file I/O or network calls |
| **5. User Input Handling & Configuration Files:**
    *   Learn `configparser`, `argparse` again, or even the older `ConfigParser`
    *   Understanding INI file format parsing
    *   Examples: Create a script that reads configuration from `/etc/myapp/settings.ini`. Parse and modify DNS server IPs stored in a simple text config |

### Phase 3: Advanced Concepts & Infrastructure Integration

Expand your Python capabilities for more complex automation, monitoring, and integration tasks.

| **Topic** | **Learning Resources (Examples)** |
|---|---|
| **1. User Management:** Learn to manipulate user accounts with safer alternatives or specific system calls.
    *   Using `getpass` for secure password input (if needed)
    *   Using the `pwd` and `grp` standard libraries – useful for checking user/group existence, getting uid/gid names
    *   Using external modules like `python3-ldap` if integrating with Active Directory or similar.
    *   Examples: List users matching a specific group ID. Check if a certain user exists locally (using `/usr/bin/id`). Script that adds a new system user from command-line arguments |
| **2. Environment Variables:** Use and set environment variables within your scripts and for execution context.
    *   Accessing common ones (`os.getenv()`, `os.environ`)
    *   Setting environment variables for subprocess commands
    *   Examples: Check if a script requires an environment variable like `$HOME` to exist. Set the `PATH` environment temporarily for another command using `subprocess.run()` |
| **3. More Advanced Looping & Control Flow:** Efficiently process lists and handle common system tasks iteratively.
    *   Loops with error handling
    *   Using list comprehensions effectively
    *   Examples: Iterate over lines of a log file filtered by a regex pattern (from Phase 1). Iterate over users listed in `/etc/passwd`. Loop through multiple directories |
| **4. Introduction to Asyncio:** Learn asyncio for I/O-bound operations.
    *   Basic `async`/`await` syntax
    *   Understanding coroutines and futures (`async def`, `await`)
    *   Using async with the `aiohttp` library (for web API interaction) or exploring specific libraries like `aiogpio` if needed for hardware interactions |
| **5. Introduction to Text Templating:** Use Python's string formatting power.
    *   F-strings (`f"{variable}"`) in Python 3.6+
    *   `.format()` method
    *   `%` formatting (for backward compatibility)
    *   Basic template strings – useful for creating dynamic config or messages
    *   Examples: Construct a status report string using f-strings with variables from your script. Create a simple Ansible-style `jinja2` template snippet |

### Phase 3: Advanced Automation, Integration & Best Practices

Once you're comfortable with scripting techniques and basic system interaction, focus on making scripts more maintainable, deployable, and integrating with other systems or services.

| **Topic** | **Learning Resources (Examples)** |
|---|---|
| **1. Version Control for Scripts (`git`):**
    *   Understand Git basics: commit messages, branching (`feature/branches`)
    *   Using `subprocess` to integrate simple scripts into deployment workflows
    *   Basic CI/CD integration – maybe using GitHub Actions or Jenkins if you're on a team with these.
    *   Examples: Version control your automation script. Use Git tags for different stable states (e.g., production vs testing). Create a basic `Makefile`-like script that builds and deploys changes via commit hook or CI/CD job |
| **2. Virtual Environments (`venv`) & Package Management:** Isolate dependencies.
    *   Creating virtual environments with `python -m venv my_env`
    *   Activating/deactivating them
    *   Installing packages (both standard and third-party) using `pip` within the environment
    *   Understanding why this is crucial for avoiding system-wide dependency conflicts when writing scripts intended for deployment or automation |
| **3. Testing Frameworks (`unittest`, `pytest`):**
    *   Unit testing your functions with `unittest`
    *   Integration testing: Test if your script runs a command successfully and produces the expected output (use `subprocess.run()` return codes/output).
    *   Understanding test coverage
    *   Examples: Write tests for the core logic of your scripts. Verify that a log parsing function correctly extracts IPs from sample logs. Ensure user creation functions run without errors if given valid input |
| **4. Security Awareness:**
    *   Be cautious with `subprocess` arguments and raw string handling – avoid command injection vulnerabilities.
    *   Understand the basics of secure file permissions when creating files/scripts (using Octal notation, `chmod`, setting ownership).
    *   Avoid running scripts as root unless absolutely necessary and safe. Use `sudo` appropriately or run non-root users with sudo privileges only for specific commands (e.g., using `visudo`). |
| **5. Introduction to Text Templating (`string.Template`, Jinja2):** Learn how to generate text files dynamically.
    *   Using basic string formatting and placeholders
    *   Using the powerful `jinja2` templating engine (`pip install jinja2`) for complex template generation (often used for generating config snippets or reports)
    *   Examples: Create a script that generates an HTML report from log data using templates. Build dynamic Ansible playbooks by inserting variables into `.yml` files |

### Phase 4: Automation Projects & Portfolio Building

This phase involves applying your skills to automate specific, practical tasks you encounter daily.

| **Topic** | **Learning Resources (Examples)** |
|---|---|
| **1. Automate Common Tasks:** Identify one or two manual tasks and turn them into simple automation scripts.
    *   Example Task 1: "Checking disk usage".
        *   Use `subprocess` to run `df -h`.
        *   Parse the output with `re` or basic string splitting.
        *   Format a human-readable report, perhaps using `argparse` for thresholds and `logging` if it fails. |
    *   Example Task 2: "User account management".
        *   Create script to list users matching criteria (e.g., shell type).
        *   Create script to add/remove a user (requires sudo handling! - see Phase 1/2 subprocess with error checking). |
| **2. Automate Monitoring & Reporting:** Use Python for system monitoring.
    *   Check service status via `systemctl` (using `subprocess` or potentially libraries like `psutil`).
    *   Monitor log files using tail-like approaches (`tail`, `grep`) and regex parsing.
    *   Implement proper logging to track script execution and results. |
| **3. Log Analysis Scripting:** Process logs programmatically.
    *   Read rotated log files (handle gzipped formats? Use `gzip` module).
    *   Filter, count occurrences of errors/warnings using loops and conditionals/regex.
    *   Generate basic reports (e.g., top users by disk space from `/var/log/...`, common error types). |
| **4. Configuration Management Basics:** Learn how to script configuration deployment or updates.
    *   Use `argparse` for multiple hosts or servers as input.
    *   Use subprocess heavily to run commands on remote machines via SSH (consider using libraries like `paramiko` or `fabric`, but start simple).
    *   Read a config file, iterate through its contents and execute corresponding commands. |
| **5. Network Scripting Basics:**
    *   Basic interaction with network services – use the standard `socket` library for very basic stuff.
    *   Using libraries like `requests` or `urllib.request` to query simple HTTP APIs (e.g., API endpoints, Nagios checks).
    *   Parsing results from web services. |

### Phase 5: Advanced Topics & Scaling

Once you're comfortable with the core tools and techniques, explore these areas:

1.  **Security:** Learn about secure coding practices – input sanitization when using `subprocess`, handling credentials securely (use environment variables or encrypted files), understanding risks of running scripts remotely (`paramiko` for SSH, avoid simple password storage).
2.  **Concurrency/Parallelism:**
    *   Basic threading (`threading`) for tasks like monitoring multiple services simultaneously.
    *   Introduction to the `asyncio` module for asynchronous I/O (e.g., pinging many hosts concurrently). This might require revisiting loops and async concepts from Phase 1 in a new context. Consider using libraries like `concurrent.futures`.
3.  **Configuration Management Integration:**
    *   Learn how system admin tools interact with CMDBs/APIs (if used).
    *   Explore Ansible's Python library (`ansible-runner`) or SaltStack for advanced integration.
4.   **Databases & Data Persistence:** Use SQLite databases to store configuration, settings, or data collected from multiple sources.
5.  **GUI Automation:**
    *   GUI basics with Tkinter – automate GUI interactions on Linux systems (less common in sysadmin but useful for monitoring dashboards).
